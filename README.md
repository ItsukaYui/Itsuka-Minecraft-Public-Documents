# Introduction

Files in this repo are named under the same method. 
For example: 

#### AP-building-ControlTower-NETA-KIX.schem

    AP: The class of this file. 
    
    building: The subclass of this file under the soperclass AP. 
    
    ControlTower: The name of this file. 
    
    NETA: This is an optional tag. Name contains this tag means that the works is an adaptation of the references below. 
    
    KIX: This is the reference of this work in the real world. 

## Buildings

### Airport

This folder contains several works about an airport. They were divided into several subclasses: 

#### building

    This is buildings in an airport, such as terminal building, control tower & etc. 

#### runway

    This is several parts of a runway in the airport. Because of the size of the file, a runway was sliced into several files by the marks on it. 

#### taxiway

    This is several parts of different kinds of taxiways in the airport. Because of the size of the file, They were sliced into several files by their traits. 

### Buildings for Town

This folder contains different works for making a town. They were divided into several subclasses by their architectural styles: 

#### Medieval

    This folder contains works of medieval buildings. 

    PS: 
    Files with no optional tags are different medieval houses. 
    "slope" means the house was built on a slope. 
    "bridge" means this work is a bridge, not a house. 


### Great Buildings

This folder contains different works of great buildings around the world. 
Each file was sorted by the location of itself. 

#### PS: Great buildings about the ancient Greek, the Roman Empire and the East Roman Empire was sorted in this folder: 

    Roman-Byzantine-Greek

### Ground Flag

This folder contains map arts about different flags. Files about national flags was named by the country tags in Europa Universalis 4 (eu4) or Hearts of Iron 4 (hoi4). For example: 

    byz: Byzantine Empire
    jap: Japan

National flags in different historical times were named by optional tag "eu4" (AD1444-1820) or "hoi4" (AD1936-1945). 

### Railway

This folder contains different elements of a railway system. Most of the files are required you to load MTR mod (which is mentioned by "mtr-required"). 

Files in this repo are named under the same method. 
For example: 

#### RAIL-station-4A2underground-NS.schem

    RAIL: The class of this file. 

    station: The subclass of this file under the soperclass AP. 

    4A2underground: The name of this file. 
        "4A" means the length of the platform
        (PS: You can check the length in blocks in file "length-of-each-station.txt") 
        "2" means the number of tracks. 
        So "4A2" means "a station with 2 platforms length 4A". 
        
        "underground" means this station is an underground station. 
    

    NS: This is the towards of the station(tracks). "NS" means this station towards the direction North-South(parallel to the axis Z), and "WE" means this station towards the direction West-East(parallel to the axis X). 

### Structure Sets

This folder contains different sets, such as different National flags on the flagpoles. 

# Q&A

## Q: How to use schem files in Minecraft? 

### A: 
Find the root directory of your Game (where you put your mod files), and put the schem files you've downloaded under this directory: 

    ../config/worldedit/schematics/

For example, if your game stored under: 

    D:/Minecraft/.minecraft/versions/1.20.1/

Then put files under: 

    D:/Minecraft/.minecraft/versions/1.20.1/config/worldedit/schematics/

Then start the game and enter the command (e.g. load file ABC.schem): 

    //schem load ABC

and use

    //paste

to paste the work in the file into your world. 

## Q: What's the tricolour in your files?

### A: 

It's the flag of my private Minecraft server, Sekisui,  where most of the schem files are created in it. 

It offers the status of a waving flag. You can replace it by your own flags instead of designing it by yourself, which makes it easy to create your own skylines.
